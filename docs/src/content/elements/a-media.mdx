The `a-media-*` elements are unstyled controls for a native `<audio>` or `<video>` element.
Place the media element and any controls inside an `<a-media>` container. The controls read the state of the media element and update on its media events, no player library is needed.
They are used by the [Audio](/components/audio/) and [Video](/components/video/) components.

| Element | Description |
|---------|-------------|
| `a-media` | Container. Controls inside of it control its `<audio>` or `<video>` element. |
| `a-media-play` | Toggles playback. Slots `play` and `pause`. |
| `a-media-mute` | Toggles mute. Slots `mute` and `unmute`. |
| `a-media-skip` | Skips by `seconds`, negative values skip backward. |
| `a-media-rate` | Cycles through playback `rates` and renders the current rate. |
| `a-media-time` | Displays the `current`, `duration` or `remaining` time. |
| `a-media-seek` | Seek slider, extends [`a-range`](/elements/a-range/). |
| `a-media-volume` | Volume slider, extends [`a-range`](/elements/a-range/). |

## Accessibility

- **Buttons**: The button elements get `role="button"` and are focusable. They activate on click, <kbd>Enter</kbd> and <kbd>Space</kbd>. The accessible name comes from the slotted content, so include text (visually hidden if needed).
- **Sliders**: Seek and volume have `role="slider"` and a readable `aria-valuetext`, like "1:30 of 9:12" or "50%". Name them with the `label` attribute.
- **Keyboard**: On the seek slider <kbd>←</kbd>/<kbd>→</kbd> seek by `key-step` seconds (default 5), <kbd>Home</kbd>/<kbd>End</kbd> jump to the start or end. On the volume slider the arrow keys change the volume by `key-step` (default 0.1).
- **Disabled state**: `a-media-skip` gets `aria-disabled="true"` and the seek slider is disabled while the duration is unknown.
- **Volume**: `a-media-volume` is hidden on platforms that don't allow changing the volume, like iOS. Muting still works there.
- **Group**: Give the `<a-media>` container `role="group"` and an `aria-label`, so the controls are announced together.

## Usage

```ts
import "@atrium-ui/elements/media";
```

```html
<a-media role="group" aria-label="Episode 12">
  <audio src="episode.mp3" preload="metadata"></audio>

  <a-media-play>
    <span slot="play">Play</span>
    <span slot="pause">Pause</span>
  </a-media-play>

  <a-media-skip seconds="-15">Back 15 seconds</a-media-skip>
  <a-media-skip seconds="30">Forward 30 seconds</a-media-skip>

  <a-media-time type="current"></a-media-time> / <a-media-time type="duration"></a-media-time>

  <a-media-seek label="Seek"></a-media-seek>

  <a-media-rate rates="[1, 1.5, 2]">
    <span class="sr-only">Playback speed</span>
  </a-media-rate>

  <a-media-mute>
    <span slot="mute">Mute</span>
    <span slot="unmute">Unmute</span>
  </a-media-mute>

  <a-media-volume label="Volume"></a-media-volume>
</a-media>
```

### Video

The same controls work with a `<video>`. For fullscreen, gestures, hotkeys or auto hiding controls, combine them with a [Video.js](https://videojs.org/) player, like the [Video](/components/video/) component does.

```html
<a-media>
  <video src="video.mp4" playsinline></video>

  <a-media-play>
    <span slot="play">Play</span>
    <span slot="pause">Pause</span>
  </a-media-play>

  <a-media-seek label="Seek"></a-media-seek>
</a-media>
```

## Customization

- **Container**: `<a-media>` has no styles of its own, it is an inline element by default.
- **Buttons**: Style the elements directly, they are the buttons. Use the slots to swap icons per state.
- **Sliders**: Seek and volume use the [`a-range` custom properties and parts](/elements/a-range/#styling). The seek slider shows the buffered part of the media from the current time, styled with `--range-buffer-background` or `::part(buffer)`.
- **Time and rate**: `a-media-time` renders plain text with tabular numbers, `a-media-rate` renders the rate as text like `1.5×`.
