The Map component renders an interactive [Mapbox GL JS](https://docs.mapbox.com/mapbox-gl-js/) map centered on a given location.
It uses cooperative gestures, so the page keeps scrolling normally: zooming needs <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + scroll on desktop and two fingers on touch devices.
Changing `lat`, `lng` or `zoom` animates the map to the new position.

The zoom and recenter controls and the marker are our own markup, styled with Tailwind and Atrium icons instead of Mapbox's default UI.

Requires the `mapbox-gl` package and a [Mapbox access token](https://docs.mapbox.com/help/getting-started/access-tokens/).

## Guidelines

- **Pair with an address**: Always show the address as text too. A map alone is hard to copy from and is not accessible to everyone.
- **Attribution**: Mapbox's terms require their logo and attribution to stay visible. The component keeps them in a compact form.
- **Client only**: Mapbox GL needs a browser. With SSR frameworks like Nuxt, render the component client-side only (e.g. inside `<ClientOnly>`).
  Be careful with layout shifts: nothing is rendered on the server, so reserve the map's space with a placeholder of the same size (e.g. the `#fallback` slot of `<ClientOnly>`).
- **Tokens**: Use a public (`pk.*`) token restricted to your domains. Never ship a secret token.
- **Privacy**: The map loads data from Mapbox servers. Depending on your jurisdiction, you may need user consent before rendering it.

## Accessibility

- **Label**: The `label` prop labels the map region for screen readers. Describe what the map shows.
- **Scroll safety**: Cooperative gestures prevent users from getting stuck in the map while scrolling the page.
- **Controls**: Zoom and recenter are native buttons with accessible labels and visible focus outlines.
- **Keyboard**: The map can be focused and panned with the arrow keys and zoomed with <kbd>+</kbd>/<kbd>-</kbd>.
