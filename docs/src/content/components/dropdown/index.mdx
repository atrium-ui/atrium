The Dropdown provides a button-triggered menu for presenting a list of actions or navigation links. It combines [a-popover](/elements/a-popover) for positioning and [a-list](/elements/a-list) for keyboard-navigable options.

## Example

Click the button to reveal the dropdown menu with selectable options.

## Menu

`DropdownItem` takes an `icon` slot, a `shortcut` for keyboard hints and a `danger` flag for
destructive actions. `DropdownSeparator` groups them.

<Story id="dropdown--menu" />

```vue
<Dropdown label="Document" placements="bottom-start,top-start" width="260px">
  <DropdownItem shortcut="⌘ L">
    <template #icon><ClockIcon /></template>
    Activity
  </DropdownItem>

  <DropdownSeparator />

  <DropdownItem danger @click="archive">Archive Document</DropdownItem>
</Dropdown>
```

### Props

**Dropdown** — `label`, `placements`, `width`, `class`; slots `trigger` and default; emits `change`.

**DropdownItem** — `href` (renders an anchor), `shortcut`, `danger`, `disabled`, `keepOpen`, `class`; slots `icon` and default; emits `click`. Clicking an item closes the dropdown unless `keepOpen` is set.

## Accessibility

- The menu can be navigated using arrow keys
- Pressing Enter or Space activates the focused option
- Escape dismisses the dropdown and returns focus to the trigger
- The trigger button indicates the expanded/collapsed state via ARIA attributes
